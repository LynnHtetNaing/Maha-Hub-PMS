Maha Hub Group of Companies - website

The website is plain HTML, CSS and JavaScript at the root of this repository (GitHub Pages serves it at maha-hub.com).
Pages are generated from one file so the header, footer and design stay the same everywhere.

  Edit the words / pages ...  website/build.mjs        (home, about, Solutions, Academy, products, pricing, contact)
  Edit the legal text ......  website/content/*.html   (privacy, terms, refund, security, password page script)
  Edit the look ............  assets/group.css
  Edit the behaviour .......  assets/group.js
  Rebuild the pages ........  node website/build.mjs   (needs Node.js 18 or newer)

Pages: / (home), /about, /maha-hub-solutions, /products, /pricing, /security, /maha-hub-academy, /contact,
       /privacy, /terms, /refund, /reset-password.html (used by the sign-in password email), /404.html

Not part of the website, do not overwrite: /solutions (the PMS sign-in page), /solutions-PMS, /ecosystem/ (older address of the apps and the
other systems), /reach/, /connect/, /book/, /sales/, /edc-link/, /brand/, /icons/, /sw.js.

Colours (from the logo): green #113732, gold #C9A55A, ivory #F1E5C9.
Brands: Maha Hub Solutions (technology) and Maha Hub Academy (education), under Maha Hub Group of Companies Limited.
